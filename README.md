# 红色警戒2共和国之辉（Ubuntu 24.04）

我已经在这个目录里准备好了两个脚本：

- `setup_ra2_gh.sh`：安装 Wine 并初始化游戏运行环境
- `run_ra2_gh.sh`：启动安装包或游戏本体

## 你现在要做的事

1. 把“共和国之辉”的安装包，或者已经解压好的完整游戏目录，放到当前目录下的 `game/` 里。
2. 在这个目录打开终端，执行：

```bash
chmod +x setup_ra2_gh.sh run_ra2_gh.sh
./setup_ra2_gh.sh
```

3. 如果你放进去的是安装包，例如 `setup.exe`，执行：

```bash
./run_ra2_gh.sh setup.exe
```

4. 如果你放进去的是已经能直接运行的游戏目录，执行：

```bash
./run_ra2_gh.sh
```

## 分辨率设置（自定义配置）

游戏现在支持通过 `config.ini` 控制分辨率，启动时会自动生效。

默认行为：

- `AUTO_DETECT=true` 时，脚本会自动读取当前主显示器分辨率。
- 这对你这种会在 `2560x1440` 外接屏和笔记本屏之间切换的情况最省事。

如果你想手动固定分辨率：

1. 用文本编辑器打开当前目录下的 `config.ini`。
2. 把 `AUTO_DETECT=true` 改成 `AUTO_DETECT=false`。
3. 修改 `SCREEN_WIDTH` 和 `SCREEN_HEIGHT`。
4. 保存后，直接运行 `./run_ra2_gh.sh` 启动游戏即可。

**推荐分辨率（稳定度从高到低）：**

| 分辨率 | 适合场景 | 说明 |
|--------|----------|------|
| **1024 x 768** | 老玩家首选 | 最稳定，UI大小适中，兼容性最好 |
| **1280 x 800** | 宽屏笔记本 | 视野较好，UI不会太小 |
| **1366 x 768** | 常见笔记本 | 主流笔记本屏幕分辨率 |
| **1600 x 900** | 高清体验 | 清晰度高，UI稍小 |
| **1920 x 1080** | 大屏推荐 | 全高清，最清晰，但UI会变小 |

> 提示：如果改了高分辨率后进游戏黑屏或闪退，把分辨率改回 **1024x768** 再试。

## 如果你还没有游戏文件

最稳妥的方式是用你自己已有的光盘、备份或正版来源取得游戏文件，再放进 `game/`。

如果你走正版路线，可以优先考虑在 `Steam` 里安装《Command & Conquer: The Ultimate Collection》；不过“共和国之辉”本身是基于原版红警2的非官方改版，所以仍然需要你自己已有的对应游戏文件或模组文件。

## 常见情况

- 双击没反应：先在终端里运行脚本，能看到报错信息。
- 黑屏或分辨率异常：通常是老游戏兼容性问题，先确认你启动的是正确的 `exe`，必要时我可以继续帮你加兼容补丁。
- 找不到启动文件：直接运行 `./run_ra2_gh.sh`，脚本会自动在 `game/` 里找常见的 `.exe`。
